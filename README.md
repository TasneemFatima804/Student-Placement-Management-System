# Student Placement Management System

## Overview
The Student Placement Management System is a C++ console-based application that helps manage student placement and internship records.

The system allows faculty members to add, edit, delete, search, and manage student information while storing all records in a CSV file that can be opened in Microsoft Excel.



## Features

- Add Student
- View Student Records
- Search Student by Roll Number
- Faculty Login
- Student Login
- Edit Student Details
- Delete Student Record
- Password Authentication
- CSV File Storage
- Excel Compatible Data



## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- CSV Storage
- Microsoft Excel



## How to Run

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Compile the program using a C++ compiler (g++).
4. Run the executable.
5. Use the menu to manage student placement records.
